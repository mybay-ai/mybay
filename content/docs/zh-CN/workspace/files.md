## 文件来自哪里

Agent 在实例工作区中生成的文件可以出现在对话消息和文件管理页面中。受支持的类型可以预览，其他类型只会在安全策略允许时提供下载。

文件路径必须属于当前实例工作区。服务端会校验实例身份、规范化路径，并阻止目录穿越和跨实例读取。

> [!NOTE]
> 对话中出现一段看起来像路径的文本，不表示它一定可以下载。文件必须真实存在，并通过路径和类型检查。

## 预览与下载

文件卡片不可用时，检查文件是否被移动或删除、管理员会话是否有效、路径是否属于当前实例，以及文件类型和大小是否满足策略。大型文件或不支持的格式应下载后使用可信的本地工具打开。

## 敏感文件保护

不要通过工作区页面分享或导出：

- `.env` 和包含环境密钥的配置。
- 私钥、证书私钥和模型凭据。
- 带有 Authorization 请求头或内部路由密钥的日志。
- 来源不可信、内容未知的压缩包。

服务端限制是最后一道保护，不能替代 Agent 任务本身的最小权限设计。

## 磁盘使用

`DEFAULT_INSTANCE_DISK_MB` 是本地主机保护默认值，不是外部计费额度。交付物、附件、缓存、日志、任务状态、依赖和工作区内容都会增加 `data/` 占用。

定期清理确认不再需要的临时文件。删除实例或工作区内容前，先下载需要保留的交付物。

## 备份与恢复

升级、迁移或批量清理前，停止写入并备份 `.env` 与完整 `data/`。只复制单个数据库文件可能遗漏实例配置、工作区和其他运行数据。

```bash
docker compose stop
# 使用自己的备份工具复制 .env 和 data/
docker compose start
```

备份可能包含凭据和业务文件，应加密保存并限制访问。恢复后检查实例列表、文件预览以及 BYOK 凭据能否解密。

## 无法打开文件时

刷新管理员会话，检查控制面板日志中的路径、权限或响应头错误，并确认实例没有正在删除或重建。不要通过修改 URL 绕过路径检查。

其他运行问题请参阅[常见故障排查](/docs/troubleshooting/common)。
