## BYOK 是什么

BYOK（Bring Your Own Key）表示使用你自己的模型供应商账号和 API Key。麦贝开源版不会提供托管模型额度；模型调用费用、可用区域和速率限制由你的供应商决定。

## 新增凭据

1. 登录本地控制台。
2. 打开“凭据管理”。
3. 点击“新增凭据”。
4. 填写便于识别的名称。
5. 选择模型供应商类型。
6. 输入真实 API Key 并保存。

凭据由服务端使用 `ENCRYPTION_KEY` 加密后写入本地数据存储。列表接口只返回脱敏结果，不会把完整 Key 发回浏览器。

> [!DANGER]
> 不要把 API Key 写入文档、截图、聊天消息或 Git 仓库。不要提交包含凭据的 `.env` 和 `data/`。

## 在实例中使用凭据

创建或编辑实例时，选择模型供应商和已保存凭据，再选择该供应商支持的模型。凭据解析失败或已被删除时，部署会拒绝继续，避免把无效配置写入实例。

开源版以 BYOK 为默认模型来源，不提供托管模型选择。

## 自定义兼容服务

选择自定义类型后可以填写 OpenAI 兼容的 Base URL，例如自托管网关或本地模型服务地址。

Base URL 会经过服务端 SSRF 安全校验。指向受保护的内部地址、非法协议或无法通过安全策略的地址会被拒绝。

> [!TIP]
> 本地模型服务必须能够从 麦贝控制面板或 Agent 容器所在网络访问。浏览器能够打开该地址并不代表容器能够连接。

## 更新和轮换

编辑凭据时，保留脱敏占位符不会覆盖原 Key。需要轮换时输入新的真实 Key 并保存，然后重新部署或更新使用该凭据的实例。

更换 `ENCRYPTION_KEY` 前必须先设计凭据迁移方案；直接更换会导致旧凭据无法解密。

## 删除凭据

删除前确认没有实例继续依赖它。删除凭据不会自动为已有实例选择其他模型配置，相关部署、更新或任务可能失败。

## 常见问题

- 保存被拒绝：检查名称、类型和 API Key 是否完整，确认输入的不是脱敏占位符。
- 自定义地址被拦截：检查协议、域名和 SSRF 安全限制。
- 模型请求返回 401/403：在供应商控制台确认 Key 有效、权限正确。
- 容器连接失败：检查 DNS、代理、Docker 网络和供应商区域限制。
- 已保存但实例仍使用旧配置：重新保存实例配置并执行更新或重新部署。
