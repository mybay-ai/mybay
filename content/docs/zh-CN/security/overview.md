## 明确信任边界

麦贝开源版采用单个本地管理员账号。管理员能够管理凭据、实例、文件和系统设置，因此只应由可信人员使用。

首次启动后立即设置强密码。公网部署时，建议在 HTTPS 之外增加 VPN、IP 白名单或其他入口访问控制。管理员会话使用受保护的 Cookie，不要在公共电脑登录或共享浏览器数据目录。

## 保护密钥和凭据

模型凭据使用 `ENCRYPTION_KEY` 在服务端加密保存。`MYBAY_INTERNAL_ROUTING_SECRET` 用于控制面板与实例内部路由之间的鉴权。

以下内容不得进入 Git、公开 Issue、聊天记录或截图：

- `.env` 的真实内容。
- 模型 API Key。
- 管理员密码、JWT 密钥和内部路由密钥。
- 带有 Authorization 请求头的请求记录。

更换模型 Key 时，先在供应商侧创建新 Key，更新 麦贝凭据并验证实例，然后再撤销旧 Key。

> [!DANGER]
> 不要直接更换 `ENCRYPTION_KEY`。没有凭据迁移方案时，旧凭据可能无法继续解密。

## 谨慎使用 Docker Socket

Docker Socket 具备很高的宿主机权限。只在可信主机运行控制面板，并遵守以下原则：

- 不通过公网 TCP 暴露 Docker daemon。
- 不把 Docker Socket 挂载给不可信容器。
- 只启用确实需要的 Docker 管理能力。
- 定期检查运行中的容器、镜像和异常端口映射。

## 收紧网络入口

不同部署模式采用不同边界：

- desktop：控制台和动态端口只绑定 `127.0.0.1`。
- LAN：只绑定指定的可信私网地址，并配置主机防火墙。
- server：通过 Traefik 暴露 80/443，实例内部端口不直接公开。

公网模式必须使用真实域名和有效 HTTPS。切换模式后重新部署实例，以更新旧 URL、绑定地址和代理标签。

## 保护文件和备份

实例文件只能通过经过身份和路径校验的接口访问。不要通过公开静态目录提供整个 `data/`。

备份 `.env` 和 `data/` 时，应停止写入、使用加密介质、限制读取权限、保留恢复所需的原始 `ENCRYPTION_KEY`，并定期执行恢复演练。

有关工作区限制，请阅读[文件、预览与本地存储](/docs/workspace/files)。

## 安全事件处理

发现凭据泄露时，立即撤销供应商 Key、更新 麦贝凭据并重新部署相关实例。管理员密码或环境密钥泄露时，应隔离主机、轮换相关密钥并检查日志。

公开提交问题前删除 API Key、Authorization 请求头、真实域名、内部地址、用户文件和路由密钥。不要上传完整 `.env`、数据库或备份。
