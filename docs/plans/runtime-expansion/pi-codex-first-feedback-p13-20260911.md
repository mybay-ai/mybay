# P1.3 Pi / Codex 首段反馈优化与验收

## 结果

P1.3 已在本地 `0.1.29-preview.1-p13` 控制端完成。发送 Agent 任务后，页面会立即展示当前生命周期阶段；首段正文到达后阶段卡自动隐藏，完成或停止的历史消息不会保留这些内部生命周期标记。

## 修改

- 首段正文前仅显示最新的运行阶段，例如“Agent 任务已排队”“连接 Agent Runtime 中”“Agent 正在处理请求”或 Runtime 提供的安全阶段说明。
- 正文开始输出后，阶段说明自动让位给正文。
- 生命周期与最终生成标记不计入工具步骤数。
- Pi、Codex、Hermes 的动态 Runtime 连接标题共用中英文翻译。
- 活跃阶段增加 `aria-live="polite"`，辅助技术可以感知状态变化。

## 延迟边界

服务端本轮从 Runtime 派发到首个可见文本约为 Pi 3,108 ms、Codex 3,943 ms。P1.3 优化了首段文字前的产品反馈，未宣称缩短模型本身的首 Token 时间。实际首 Token 仍会受到模型、推理档位、账号服务层和请求内容影响。
