# P1.2 Pi / Codex 流式体验验收记录

## 结果

P1.2 在 Windows x64 + Docker Desktop 的本地 `0.1.29-preview.1` 控制端完成真实验收。Pi 与 Codex 都通过文本增量、取消、同会话重新生成和刷新恢复；桌面端与 390×844 移动端均完成观察。

## 本轮修复

- `message.delta` 到达时先持久化累计的 `partial_output`，再发布事件。
- 终态写入等待已有的增量持久化任务，取消后保留已经显示的内容。
- 运行详情和会话恢复在活跃运行期间优先使用内存中的最新累计文本。
- 最新一条已完成回答增加“重新生成”，在同一会话创建新的 Run。
