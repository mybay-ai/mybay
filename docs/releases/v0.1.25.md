# v0.1.25

2026-08-31

This version improves the local Agent workspace and maintenance tools while preserving the self-hosted SQLite, Docker, and BYOK model.

## Changes

- Organize history into pinned, project, and recent groups with persistent ordering, drag handles, collapsible sections, and menu fallbacks. Titles use single-line ellipsis and hover scrolling.
- Improve conversation selection, mode and draft restoration, long-text input, history navigation, and scroll following.
- Harden cancellation, retries, queued follow-ups, empty responses, and stale-request isolation.
- Add local structured questions, execution timeline details, bounded file-change snapshots/diffs, usage evidence, and sanitized diagnostic exports.
- Improve attachment progress, cancellation, retry, duplicate-upload protection, clipboard uploads, file provenance, and preview/download handling.
- Reduce unrelated SQLite collection rewrites and improve deployment readiness feedback.
- Add isolated restore, same-image service recovery, and controlled Compose adoption commands with explicit rollback boundaries.
- Keep local acceptance artifacts and runtime data out of source distribution; retain automated tests and reusable smoke scripts.

## Upgrade and validation

Back up configuration and data consistently before replacing the control plane. Preserve local `.env`, encryption keys, Agent files, and databases. The ZIP contains source and build inputs; it does not contain a configured runtime or dependencies.

See [release validation scope](../release-validation.md) for tests that still require the final artifact and target environment. Cross-version rollback, host restart recovery, and published multi-architecture images are not certified by source checks alone. No commercial deployment or billing components are introduced.
